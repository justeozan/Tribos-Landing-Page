# Références visuelles — DA « BD cinématographique »

À fournir au modèle d'image **avec** le prompt : le texte seul ne garde pas la
mascotte cohérente. Le renard canonique est partagé par tous les presets :
**`docs/brand/mascotte/`**. Ici, un dossier par rôle (§3 du skill) :

| Dossier | Contenu attendu |
|---|---|
| `hero/` | Scènes cinématiques de référence (décor peint, lumière dorée, zone calme pour le titre). |
| `exercices/` | Poses de démonstration : angle constant, articulations lisibles, fond simple. |
| `groupe/` | Scènes collectives : interactions, encouragement, célébration. |
| `produit/` | Petites illustrations d'interface : fond crème ou uni, une action. |
| `palette/` | Nuanciers, planches couleur, ambiances lumineuses. |

## Conventions

- Noms de fichiers en minuscules et explicites :
  `renard-face.png`, `hero-montagne-coucher-soleil.jpg`.
- PNG pour la mascotte (fond transparent si possible), JPG ou WebP pour les
  scènes.
- Une ligne par fichier dans la section ci-dessous : origine et droits
  (création maison, IA avec quel outil, banque d'images et licence). Une
  image dont on ne connaît pas les droits sert d'inspiration, jamais d'asset
  publié.
